# Responsive Blog Website

## Project Description
This project is a responsive blog website developed using HTML5 and CSS3. It demonstrates CSS Grid, Flexbox, fluid typography, and media queries to create a user-friendly layout that works on desktop, tablet, and mobile devices.

## Features
- Responsive header with navigation links
- Blog post cards with images and descriptions
- CSS Grid for the overall page layout
- Flexbox for blog card alignment
- Fluid typography using `clamp()` and `vw` units
- Sidebar with About Me and Categories sections
- Responsive design using CSS media queries
- Footer section

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. View the responsive blog website.

## Responsive Design
The website supports different screen sizes:
- Desktop: Two-column layout with posts and sidebar.
- Tablet: Single-column main layout.
- Mobile: Vertically arranged blog cards with full-width images.
